# 🧩 Puzzle Game

An Android puzzle game developed using **Kotlin** and the Android SDK. The game allows players to solve image puzzles with multiple difficulty levels while providing a smooth and enjoyable user experience.

---

## 📱 Overview

Puzzle Game is a mobile application where players rearrange shuffled image pieces to complete the original picture. The application supports multiple puzzle sizes, image categories, sound effects, and a clean, user-friendly interface.

This project was built to practice Android application development and object-oriented programming while focusing on creating a complete and functional mobile game.

---

## ✨ Features

* 🧩 Multiple puzzle difficulty levels
* 🖼️ Various image categories
* 🎵 Background music and sound effects
* 🌙 Dark / Light theme support
* 🏆 time tracking
* 📂 Local image management
* ⚡ Smooth puzzle animations
* 📱 Responsive user interface

```bash

```

Open the project using **Android Studio**.

### Build
